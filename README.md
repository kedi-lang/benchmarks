# Kedi Benchmarks

Reproducible benchmark environments and public experiment evidence for the Kedi
Programming Language.

## Experiments

- [Terminal-Bench 2.1](terminal-bench-2-1/README.md): full and targeted Kedi harness
  evaluations with Harbor-authoritative results and replayable Autobench records.
- [Agent-led compaction](agent-led-compaction/README.md): who should manage an agent's context, the
  provider's native compaction or the agent itself? Pre-registered tests, raw records and a uv environment.
